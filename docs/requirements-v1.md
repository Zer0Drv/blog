# 动态博客 需求确认文档 v1（Grill-me 结论）

> 生成时间：2026-09-28。本文档为搭建前的需求基线，任何口径变更需回写此文档。

## 1. 产品定位

| 项 | 结论 |
|---|---|
| 类型 | **个人博客为主**：博主发文为主，读者注册后评论互动，少数人可被授权发文 |
| 非目标 | 不做完全开放的多人社区平台（不人人可发文） |

## 2. 角色体系

| 角色 | 权限 |
|---|---|
| ADMIN（博主） | 全部权限 + 管理后台 |
| AUTHOR（被授权发文者） | 发文/编辑自己的文章 + 读者全部能力 |
| USER（注册读者） | 评论、点赞、收藏、关注、私信、个人主页 |

## 3. 内容能力

| 能力 | 口径 |
|---|---|
| 写作 | Markdown + 实时预览 与 富文本 双模式（按文章切换，存储保留源格式） |
| 图片 | 正文插图 + 封面图上传（本地/对象存储待定，v1 本地存储） |
| 组织 | 标签（多对多）+ 分类（单选树） |
| 流程 | 草稿 / 发布 / 下架；发布时间、更新时间 |

## 4. 评论系统

| 项 | 口径 |
|---|---|
| 结构 | **两层**：主评论 + 楼中楼回复（类 B 站/掘金） |
| 排序 | 时间正/倒序 + 热度（点赞数加权）两种方式可切换 |
| 互动 | 评论可点赞；回复自动 @被回复人，支持手动 @他人 |
| 通知 | @ 与回复触发通知中心消息 |

## 5. 用户互动（除评论外）

| 能力 | 口径 |
|---|---|
| 文章互动 | 点赞 + 收藏 + 浏览量统计 |
| 关注 | 关注作者/用户，关注动态 Feed |
| 私信 | 一对一私信会话；**v1 轮询**，预留消息模型，后期加 WebSocket |
| 通知中心 | 评论回复 / @ / 点赞 / 关注 / 私信 统一通知，未读数轮询 |

## 6. 账号体系

| 项 | 口径 |
|---|---|
| 注册 | 用户名 + 密码 + **邮箱验证码**（需 SMTP） |
| 登录 | 账号密码登录 + **GitHub OAuth**（架构留第三方扩展位） |
| 找回密码 | 邮箱验证码重置 |
| 防刷 | 图形验证码（注册/登录/评论等敏感动作） |

## 7. 管理后台

| 模块 | 功能 |
|---|---|
| 文章管理 | 编辑 / 下架 / 置顶 / 推荐位 |
| 评论治理 | 审核队列 + 敏感词过滤 + 删除/折叠 |
| 用户管理 | 封禁/解封、授予发文权限（USER→AUTHOR）、角色管理 |
| 站点数据 | 访问统计、活跃数据 dashboard |

## 8. 技术栈（参考 admin 项目定型）

### 后端 `E:\code\blog`（临时名，可整体改名）

| 组件 | 版本/说明 |
|---|---|
| Spring Boot | **4.1.4**（admin 为 4.1.1，同代升级） |
| JDK | 25（corretto，本机 JAVA_HOME 已配） |
| 数据库 | **MySQL 8.4 LTS**（docker 新容器；Flyway 需引 `flyway-database-mysql`） |
| 缓存 | Redis（复用现有 docker 容器）：验证码、限流、热点计数、会话辅助 |
| 安全 | Spring Security 7 + oauth2-resource-server，HS256 JWT（同 admin 口径：`R{code,data:{access_token}}`、authority-prefix ""、放行 /error、ROLE_ 只出现一次） |
| ORM | MyBatis-Plus 3.5.17（spring-boot4-starter + jsqlparser） |
| 迁移 | Flyway（MySQL 模块） |
| 其他 | MapStruct-Plus 1.5.2、Hutool 5.8.x、Lombok、spring-modulith、devtools、docker-compose support |
| 模块划分（modulith） | user / article / comment / interaction(点赞收藏关注) / message(通知+私信) / admin |

### 前端 `E:\code\blog-ui`（临时名）

| 组件 | 版本 |
|---|---|
| Vue | 3.5 + Vite 6 + **pnpm** |
| UI | Element Plus 2.9 + icons |
| 状态/路由 | Pinia 2 + vue-router 4 |
| HTTP | axios |
| 新增 | Markdown 渲染（如 md-editor-v3 / marked）、富文本（如 wangEditor）——脚手架阶段定 |

## 9. 工程与环境默认值

| 项 | 值 |
|---|---|
| 后端端口 | 8082（避开 admin 8081） |
| 前端端口 | 5173（冲突自增） |
| 数据库 | blog_dev @ 本地 docker MySQL 8.4（独立容器，端口 3307 避开可能的本机 3306） |
| 包名 | 暂定 com.zer0drv.blog（**项目名/包名后期统一改**） |
| GitHub | 私有远程 Zer0Drv/blog、Zer0Drv/blog-ui（push 走 `-c http.proxy=http://127.0.0.1:7890`） |

## 10. v1 分期建议

- **M1 骨架**：工程脚手架、Flyway 初始化、注册登录（邮箱验证码+GitHub OAuth）、JWT 安全层
- **M2 内容**：文章 CRUD（双编辑器、图片上传、标签分类）、首页/详情/列表
- **M3 互动**：评论（两层+双排序+@）、点赞收藏、浏览量
- **M4 社交**：关注+Feed、私信（轮询）、通知中心
- **M5 后台**：四大管理模块 + dashboard
